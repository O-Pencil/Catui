# Impeccable Design Context

Persistent design guidance for the Catui repository. Distilled from `.CATUI.md`
(product personality charter), the TUI theme tokens in `modes/interactive/theme/`
(`dark.json`, `light.json`, `warm.json`), and the project's stated pillars.

## Design Context

### Users
Terminal-native developers and Catui contributors who live in the CLI/TUI. They
are technically fluent, time-pressed, and skeptical of decoration that carries no
information. When they read a doc or use a surface, the job is: *understand the
system precisely and get back to work faster.* Secondary audience: curious
evaluators comparing Catui against other agents.

### Brand Personality
Three words: **warm**, **composed**, **precise**.
Per `.CATUI.md`, Catui should feel like "an unusually capable personal assistant"
— the competence of an elite chief of staff, the quiet usefulness of a Jarvis-like
operator. Natural and human, but sharp and professional. Never cold, theatrical,
robotic, clingy, or over-excited. Evidence over volume: it convinces by being
observant, not louder.

### Aesthetic Direction
Visual tone: **warm-paper editorial / engineering manuscript**. Light, inked,
bookish — a field notebook for a memory system. Deliberately *not* the default
dark-mode-with-glowing-accents look.
- Palette roots (from `warm.json` / `light.json`): warm brown `#c4a574`, amber
  gold `#d4a574`, border `#a08060`, muted teal `#5a8080`, brick `#cc6666`.
  Transposed onto a rice-paper off-white ground with warm-ink text.
- Type: a characterful serif display (e.g. Fraunces for Latin/numerals) paired
  with a readable serif for CJK body (e.g. Noto Serif SC); a real monospace
  (e.g. JetBrains Mono) reserved for code, paths, and identifiers — functional,
  not decorative.
- Structure: hairline rules instead of card boxes, asymmetric editorial columns,
  generous margins, marginalia annotations for `file:line` references, drop caps,
  numbered sections. Meaning-bearing inline SVG diagrams (architecture plates,
  decay curves), never decorative sparklines.

#### Mobile Remote Client (`apps/mobile`) — Anthropic-style warm theme
The phone/browser remote client is a light, cream-on-ink surface (deliberately
*not* dark mode), styled after Anthropic's book-cloth + terracotta language.
All tokens live in the Tailwind 4 `@theme {}` block in `apps/mobile/src/index.css`
(CSS-first; there is no tailwind.config). Views must reference these tokens, not
hardcoded Tailwind palette colors (`zinc`/`red`/`emerald`/`amber`/`black`):
- Surfaces: `bg` `#efece2` (page cream), `panel` `#faf8f2` (raised ivory),
  `panel-2` `#e8e3d6` (inset sand), `line` `#ddd7c8` (hairline border).
- Ink: `ink` `#211f1b` (primary text), `muted` `#6f6a5c`, `faint` `#9b9483`.
- Accent (terracotta): `accent` `#bf6a45` (fills), `accent-soft` `#f2e0d3`
  (pale tint bg), `accent-ink` `#8f4526` (accent *text* on light, AA contrast),
  `on-accent` `#fdf6f0` (warm-white text on accent fills).
- Semantic: `success` `#4f7a45`, `error` `#b04434`, `warning` `#9a7522`;
  user chat bubble `user-bubble` `#e6dfd0`.
- Type: `font-serif` (Iowan Old Style / Palatino / Georgia / Songti SC system
  stack — *system* fonts, not network fonts, because the Capacitor APK runs
  offline under `https://localhost`) for headings, the chat title, sheet titles,
  and markdown prose (`.md-body`); `font-sans` for UI chrome; `font-mono` for
  code, paths, endpoints, and identifiers.
- Code blocks (`.md-body pre`) stay **dark** (`#1c1a16` bg) on the cream page for
  contrast — the Claude.ai treatment. The QR scanner camera surface also stays
  `bg-black`, so any text overlaid on it must set an explicit light color
  (e.g. `text-panel`) rather than inherit the dark `ink`.
- Inputs/textareas need a base `border border-line` for `focus:border-accent` to
  show (a focus border class with no base border is a no-op).

### Design Principles
1. **Information earns every pixel.** Decoration must encode something real
   (a curve, a budget split, a layer relationship) or be removed.
2. **Warm over cold, composed over loud.** Favor calm ink-on-paper contrast and
   restraint; avoid neon, glow, glassmorphism, and gradient-text impact tricks.
3. **Evidence is the aesthetic.** Surface counts, thresholds, file paths, and
   formulas visibly — the observant voice of the charter, made visual.
4. **Respect the reader's time.** Lead with what matters, make it scannable,
   preserve nuance in margin notes rather than the main flow.
5. **Ground in existing tokens.** Reuse Catui's own theme colors and pillar
   language so artifacts feel native to the product, not bolted on.
