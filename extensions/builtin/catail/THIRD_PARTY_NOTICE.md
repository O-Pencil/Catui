# Third-Party Influence and Attribution

CATAIL is a Catui-authored workflow. It adapts architectural and methodological ideas without vendoring upstream source files or copying upstream Skill text.

## CATPAW

CATPAW informed the routing pattern: one concise entry Skill, durable project artifacts, progressively loaded playbooks, and bounded verification. CATAIL does not reuse CATPAW's UI-specific scripts or agent configurations.

Source: <https://github.com/ryanleecode/catpaw>

## K-Dense Scientific Agent Skills

The following MIT-licensed skills informed CATAIL's scientific invariants and stage boundaries: `paper-lookup`, `hypothesis-generation`, `experimental-design`, `statistical-analysis`, `scientific-visualization`, `scientific-writing`, and `peer-review`.

Source: <https://github.com/K-Dense-AI/scientific-agent-skills>
