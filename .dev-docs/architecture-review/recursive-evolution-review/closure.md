## Explicit limits and reopen conditions

Windows service/containment, cost-denominated budgets, retention cleanup and
dependency/schema evolution remain outside this release. Observation is heuristic;
insufficient comparable samples remain inconclusive. Reopen if an accepted patch
escapes file authority, alters a frozen test, duplicates remote publication, or
switches an unverified installation. A live naturally occurring repair requires
future user activity and is not claimed by fixture or connectivity tests.
