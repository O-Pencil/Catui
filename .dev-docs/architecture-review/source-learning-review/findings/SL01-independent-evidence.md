# SL01: Separate learning from acceptance

Source repair currently supplies its own visible reproduction and uses the same
model for review. Raw per-tool rates can falsely label improvement after correlated
events or changes in task mix. The running supervisor also excludes every source
learning method from repair scope.

Use a separate model and private baseline checkout for frozen hidden cases, keep
acceptance workers on the bootstrap version, match completed-run cohorts and make
only pure learning strategies eligible for adaptive edits. Different models reduce
shared blind spots but do not establish complete statistical independence.
