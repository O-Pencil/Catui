# SP01 — Separate Persona Identity from Research Method Ownership

## Evidence

Catui personas already own identity, tone, working style, presence, isolated memory, Soul state, MCP configuration, and optional persona-local Skills. CATAIL already owns scientific routing, method selection, artifact contracts, and deterministic audit. Calling both Athena and CATAIL a "scientific agent" would duplicate authority and make future changes ambiguous.

## Decision

- Athena is the scientific Agent persona.
- CATAIL is the professional research-to-publication Skill.
- Athena names CATAIL as its default method for scientific intent but does not copy CATAIL instructions or files.
- CATAIL remains globally discoverable so default coding personas can invoke it explicitly.
- Persona Manager and prompt assembly remain research-agnostic.

## Consequences

There is one owner for identity and one owner for research method. CATAIL can evolve independently of Athena, and another future persona can explicitly use the same Skill without importing or duplicating it.
