# OG01 — Replace policy instead of stacking it

The default prompt repeats brevity requirements across three locations. Its
communication section uses rigid word/list counts and confusing advice to leave
important reasoning until last. The artifact rules force a file at ten code
lines, while scheduler guidance mentions evaluator expectations and can confuse
writing a configuration with activating a service.

Replace these with a compact communication and output-format policy. Retire the
hardcoded consciousness/creator story in favor of the existing persona owner.
Retain security, authorization, context and tool contracts. Measure the assembled
default prompt using identical tools and working directory before and after.
